# 虚拟触控板 (Virtual Touchpad)

简体中文 | [English](README_EN.md)

给折叠屏手机做的「拇指虚拟摇杆」：屏幕右下角浮一块半透明触控区，拇指在里面滑动即可移动屏幕光标，
轻点就在光标处点击。单手就能点到屏幕另一侧、顶部、右上角等够不到的地方，不用换手、不用缩小整屏。

灵感来自华为 Mate X8 的「虚拟触控屏」功能，目标是让其它折叠屏（优先小米 MIX Fold / HyperOS）也能用。

## 功能

- **虚拟摇杆**：屏幕右下角半透明圆形触控区，拇指滑动带动屏幕上的光标，轻点＝在光标处点击，按住不动＝长按
- **挪板**：按住外圈满 3 秒（轻振一下）后拖动，可把摇杆拖到任意位置
- **自动收边**：闲置 10 秒后整块板滑到屏幕边外，只留贴边的一小截圆弧（露出多少可在设置里调，默认 25%）；点一下恢复原位
- **自动隐藏**：锁屏、输入法弹出、通知栏/控制中心下拉、全屏视频与游戏时自动隐藏；也可手动指定哪些应用里不显示
- **只在展开态显示**：折叠屏合起时自动不显示（短边 < 600dp）
- **控制中心开关**：提供快捷设置磁贴与静态快捷方式，可在控制中心一键开关
- **三种外观**：磨砂玻璃（对标原版灰度）、拟物内凹、摇杆帽

## 安装

1. 下载 [Releases](../../releases) 里的 APK，安装
   - 当前最新为 **v1.3.0（正式密钥签名）**；若之前装过 v1.0 或 debug 版，**需先卸载**——签名不同无法覆盖安装；v1.1 及之后可直接覆盖升级
2. 打开应用，首次会提示开启无障碍权限 —— 这是必须的：摇杆要画在其它应用之上、点击要注入到其它 App，只有无障碍服务能做到
3. 建议同时开启自启动 / 后台运行，并把省电策略设为「不限制」，避免服务被系统杀掉

## 兼容性

- Android 8.0 (API 26) 及以上
- 已在模拟器（API 35，2200×2400 展开态）上验证交互链路
- 小米 HyperOS 需在「应用设置 → 权限管理」里允许「后台弹出界面」，并允许自启动
- 华为 / 荣耀等机型未逐一测试，无障碍服务是通用机制，理论上通用

## 已知限制

- 全屏判定在部分 ROM 上不可靠（系统不下发可靠的窗口信号），因此额外提供了「不显示摇杆的应用」名单作为兜底
- 静态快捷方式在澎湃 OS 控制中心「应用快捷开关」分组里的显示需真机确认
- 三种外观风格在深色壁纸下差异偏淡

## 构建

需要 JDK 17 与 Android SDK（compileSdk 36）。

```bash
./gradlew assembleDebug
```

仓库默认使用阿里云 Maven 镜像（见 `settings.gradle`），国内网络可直接构建；如需官方源请自行替换。

## 技术要点

- 摇杆与光标都通过 `WindowManager` 添加 `TYPE_ACCESSIBILITY_OVERLAY` 窗口
- 点击注入用 `AccessibilityService.dispatchGesture`，坐标是**物理屏幕坐标**；因此光标窗口也做成「窗口本身就是光标大小、用窗口坐标定位」，避免被系统 inset 下推导致光标与落点错位
- 系统界面遮挡判定：锁屏（KeyguardManager）→ 通知栏（TYPE_SYSTEM 窗口高度 > 屏高 60%）→ 输入法（TYPE_INPUT_METHOD 窗口高度）→ 全屏（状态栏窗口消失或压成 0 高）→ 应用名单
